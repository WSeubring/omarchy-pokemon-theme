# Design context

## Product
omarchy-pokemon-theme: an Omarchy (Arch + Hyprland) desktop theme that retints
the whole desktop to a different Pokemon every day, from its own artwork.
The web piece is the installer's setup widget: a local one-page app where the
user picks colour scheme, intensity and optionally a starter Pokemon while
seeing the real rendered wallpaper and a live terminal mockup.

## Audience
Linux ricers and developers on Omarchy. Terminal-native, opinionated about
aesthetics, allergic to corporate SaaS design. They chose a Pokemon theme on
purpose: they want play, but they judge craft.

## Use cases
- One-time guided install after cloning the repo.
- Trying a choice and instantly seeing the actual desktop it produces.
- Picking a specific Pokemon and deciding today-only vs pinned.

## Tone / personality
Pokedex meets design tool: game-flavoured chrome (dex numbers, types,
shiny lore) with the precision of a colour instrument. Playful in the details,
exact in the data. Never childish, never corporate. The generated palette IS
the brand: the UI should be recoloured by the day's creature rather than
carry its own competing identity.
